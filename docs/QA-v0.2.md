## 仍需正式环境验收

### 后续真实接口排障：选项生成

本地填入真实配置后，正文请求成功，但选项请求返回空内容。独立复现显示 `finish_reason=length`、输出额度 150 token 全部用于 reasoning，`content` 为空。选项接口现单独禁用思考模式，额度提高到 600，拒绝截断、空值、重复和不完整数组，不再将空选项作为 HTTP 200 返回。修改后真实本地接口已返回 3 个有效行动选项；测试请求未推进玩家存档。

### 后续正文稳定性修复

旧版正文失败未记录结束原因，无法追溯玩家截图中那次失败的精确原因。本次统一各生成接口的非思考参数；正文使用 JSON 模式。连续测试复现后续回合 `finish_reason=stop` 但内容为纯空白，统一 assistant 历史为 JSON、修正提示词示例并强化末尾格式要求后，真实接口连续三轮正文及选项通过，耗时约 3.1 / 2.6 / 1.9 秒，无重试。测试使用独立临时故事，不改浏览器存档。

正文最多两次尝试，总等待仍受 90 秒限制；单次 40 秒，取消、认证或额度错误不自动重试。重试只生成、不提交回合；只有最后一次完整结果提交。日志仅记录结束原因、字符数和错误类型，不记录故事原文或密钥。可手动运行 `node scripts/smoke-generation.cjs` 对本机开发服务进行三轮真实接口测试（会消耗少量 API 额度）。
