# 鸢叙 · 可以参与其中的 AI 小说

> 走进小说，读到由自己影响的故事。

鸢叙是一款以小说阅读为基础的 AI 互动故事 Web 应用。你可以进入准备好的故事，也可以设定自己的世界与角色；在阅读中采取行动、提出剧情构想，参与塑造人物关系和故事走向。

它面向读小说时会想“如果我是主角”“如果剧情这样发展就好了”的读者，不要求写作经验或提示词知识。当前处于原型迭代阶段，重点打磨个人阅读与参与体验。

[在线体验](https://ai-novel-w2x5.onrender.com/) · [产品需求](docs/PRD.md) · [代表短篇玩法](docs/SUPPLY-GAMEPLAY.md)

## 怎样参与故事

| 方式 | 你可以做什么 |
| --- | --- |
| 继续阅读 | 暂时不介入，让故事自然推进；重要抉择处可选择交给故事发展 |
| 角色行动 | 点击建议选项或自由表达主角想尝试的事，结果受人物、事实和世界规则约束 |
| 剧情构想 | 提出希望后续出现的情节或关系方向，可修改和清除；它不是角色台词，也不代表事件已经发生 |
| 回溯分支 | 返回已有快照的节点，尝试另一种选择，保留原分支 |

普通故事支持阅读与参与切换。《最后的补给站》使用专门的行动与规则流程，由调查、协商和执行推进。

## 从哪里开始

**进入一个故事**：选择预设背景、人物和冲突，直接开始体验。预设提供故事起点与约束，后续正文由 AI 生成，并非完整预写小说。

- **最后的补给站**：作为临时撤离协调者，在风暴前调查、协商并安排设备与居民的去向。时间、资源、承诺和部分结局条件由程序裁定。
- **末班车证词**：核实相互矛盾的证词，寻找救命药物，并决定如何处理隐瞒真相的人。
- **灯下密信**：在城门关闭前找回求援密信，在核验与救援之间作出选择。

**创作我的故事**：选择题材，配置世界、主角与配角，可使用 AI 生成或润色设定；支持文风、叙述视角、剧情节点与目标结局设置。一句话创建仍在规划中。

## 当前能力与边界

- 支持八种题材、流式正文、建议行动、自由输入、章节摘要、人物关系、记忆与悬疑线索。
- 支持自动与手动存档、分支回溯、结局保存、TXT 正文导出和 JSON 备份导出。
- 存档保存在当前站点的本机浏览器中。登录目前不提供云同步；换设备、换域名或清理站点数据不会自动迁移。JSON 备份导入界面尚未实现。
- AI 的人物表现、叙事质量和语义一致性仍需要真实试玩验证。一般故事中的数值与长度提示不等于成熟的游戏规则或精确的完结保证。
- 《最后的补给站》采用有限的程序规则与 AI 表达结合，支持的资源、行动和协商条件有明确边界。
- 当前不提供故事公开上传、社区、作品分发或多人共创。

## 近期重点

1. 打磨一个有明确冲突、可信反馈和完整结局的代表短篇。
2. 明确阅读、角色行动和剧情构想的区别，让参与更容易理解。
3. 降低首次进入与自建故事的门槛，让行动的影响在后续正文中可感知。
4. 验证失败恢复、存档与回溯的可靠性，并补充真实读者试玩。

这些是迭代方向，不表示已经完成用户验证。长篇质量、备份导入、云同步和公开分享将分别设计与验证。

## 本地运行

需要 Node.js 20.9 或更高版本，以及可用的 DeepSeek API 配置。Supabase 认证可选，游客入口不依赖登录。

```bash
git clone https://github.com/z2875596-crypto/AI-Novel.git
cd AI-Novel
npm install
```

在项目根目录创建 `.env.local`，勿提交密钥：

```env
DEEPSEEK_API_KEY=your-api-key
DEEPSEEK_BASE_URL=https://api.deepseek.com
# 填写服务支持的模型名；代码未设置时默认 deepseek-flash
DEEPSEEK_MODEL=your-model-name

# 可选：用户认证
NEXT_PUBLIC_SUPABASE_URL=your-supabase-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key

# 可选：保活接口鉴权
CRON_SECRET=your-cron-secret
```

```bash
npm run dev
```

打开 [本地应用](http://localhost:3000)。服务端需要可用的 API Key 才能生成故事；实际模型可用性以所接服务为准。

## 技术与验证

Next.js 16 App Router、React 19、TypeScript、Tailwind CSS、Zustand；通过 OpenAI SDK 兼容接口调用 DeepSeek，Supabase 用于可选认证。

正文采用 NDJSON 流协议：预览不写入正式进度，完整响应通过校验后才提交回合。请求取消、会话隔离、存档快照与回溯由统一流程管理。

```bash
npm test
npm run typecheck
npm run build
```

自动测试使用模拟模型验证规则与流程，不证明真实模型的理解能力和小说质量。真实体验仍需验证开场、行动反馈、连续阅读和结局。

| 目录 | 内容 |
| --- | --- |
| `app/` | 页面与服务端 API |
| `components/` | 阅读、参与、配置与存档界面 |
| `lib/` | 生成流程、故事目录、规则、提示词与持久化 |
| `stores/` | 本地状态 |
| `tests/` | 流程、规则与协议测试 |
| `docs/` | 产品需求、玩法与验收记录 |

保留 Vercel 配置；仓库另有 Render 部署记录。线上可用性与部署状态需单独确认。
